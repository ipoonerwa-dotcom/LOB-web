# LOB Admin Panel

LOB 代币的**管理后台**（TRC20 · TRON 主网 · v2）。单文件 HTML，无需构建、无依赖。

支持 **PC / 手机** 两端：
- **PC**：Chrome / Edge / Firefox 装 TronLink 插件
- **手机**：TronLink App 内置 DApp 浏览器

## 合约规则

| 功能 | 说明 |
|------|------|
| 交易开关 | owner 调 `openTrading()` 打开，**只能开一次，打开后永久开放，谁都关不掉** |
| 开盘前 | 只要转账的一方是合约（SunSwap 池子、路由等），另一方就必须在白名单 → 只有白名单能买、卖、加池子 |
| 钱包互转 | **任何时候都不受限制**（包括开盘前），往交易所充值也不受影响 |
| 白名单 | owner 单个或批量设置；**只能加普通钱包，合约地址会被拒绝**；开盘后白名单不再有任何特权 |
| 转移 owner | `transferOwnership(新地址)`，一步到位，**地址填错就永久失去权限，务必核对** |
| 弃权 | `renounceOwnership()`，**只能在打开交易之后**（防止弃权后交易永远打不开） |
| 没有的功能 | 没有手续费、没有黑名单、没有暂停、不可升级、不能增发 |

只有 owner 能操作，其他钱包连上后台是只读。

## 上线顺序（很重要）

1. **部署钱包先建池、加流动性**（SunSwap V2，LOB/USDT）。**在这之前不要给任何人转币** —— 池子地址可以提前算出来，拿到币的人可能抢先建池、自己定开盘价。加池前先确认池子还不存在或储备为 0。
2. **再分币、设白名单**：给需要提前买卖的钱包转币、加白名单。
3. **后台点「打开交易」**：打开后所有人都能自由买卖。
4. （建议）开盘后**弃权**，检测工具就不会再标"有白名单权限"。

开盘前白名单用户买卖：直接用 SunSwap **V2 路由**，收款地址填**自己**（聚合路由、代买给别人都会被拦）。开盘前撤池子用普通 `removeLiquidity`，收款地址填自己。

## 手机端使用

1. 装 **TronLink App**（App Store / Google Play / https://www.tronlink.org），导入 owner 钱包，切到 **TRON 主网**，存点 TRX 做 gas（几十 TRX 够用）
2. TronLink App → 底部 **「发现」/「Discover」** → 地址栏输入本后台网址
3. 普通手机浏览器（Safari / Chrome）打开会提示"没检测到 TronLink"，必须在 TronLink App 里打开

## PC 端使用

1. 装 TronLink 浏览器插件，导入钱包，切到 TRON 主网
2. 打开后台（推荐本地起服务：`python -m http.server 8890`，浏览器打开 http://localhost:8890）
3. 右上角「连接 TronLink」→ 合约地址填 `TW4SJrdnPNewLshAJ8GcYncbtKu5QbUhuF` → 点「加载」

## 常见操作

- **打开交易**：「交易开关」→「打开交易」，会弹两次确认。不可撤销。
- **单个白名单**：填地址 →「加入」/「移出」/「查询」
- **批量白名单**：一行一个地址（也支持逗号、空格分隔，自动去重）→「批量加入」/「批量移出」/「批量查询」，一笔交易搞定
- **转移 / 弃权**：「所有权」卡片。弃权按钮在开盘前是灰的。

每笔写操作都会**先免费模拟**，拿到真实能量消耗和失败原因后才让你确认发送；模拟失败就不会发，避免 feeLimit 被烧掉。

## 常见报错

| 提示 | 原因 |
|------|------|
| 不是 owner | 当前钱包没有权限 |
| 白名单只能加普通钱包，不能加合约地址 | 填的是池子、路由或其他合约地址 |
| 交易开关还没打开 | 开盘前不能弃权 |
| 交易开关已经打开过了 | 重复点了「打开交易」 |
| 地址不能是零地址 / 批量列表是空的 | 输入有误 |
| 429 / 接口超时 | TronGrid 免费额度 3 次/秒，等几秒再试 |
| OUT_OF_ENERGY | TRX 余额不够付能量，充值后重试 |
