合约里 MAX_PROTECT_WINDOW 是 constant = 100000 小时，写死在字节码里；openAt 一旦设定只能提前、不能推迟。 也就是说：openAt 到期后全员必定可以卖出、owner 无法把开盘时间往后推，但硬上限本身很宽松，实际防夹时长完全取决于你在 launch() 前设的 protectWindow（建议 300–900 秒）。

开盘控制

建议 300–900 秒。设 0 = 启动即全开，没有防夹。默认值是 180000000 秒（≈5.7 年），launch() 前务必显式改小，否则会把开盘时间推到几年后。
加完流动性、注册好池子地址之后再调。只能调一次。

池子地址

加流动性后，把 SunSwap 生成的 pair 地址登记进来，防夹窗口才知道哪笔是"卖出"。 开盘后这个设置不再有任何作用。

卖出白名单

窗口内可以提前卖出（做市/团队用）。开盘后白名单不再有任何特权，所有人一样。

Admin 委托（可选）

Admin 是 owner 的受限委托：只能改白名单，其它任何操作都不能做（不能 launch / 改 pair / 改窗口 / 转/弃 owner）。 Owner 可以随时更换或清零 admin。owner 弃权时 admin 不会被清零 —— 若不希望遗留 admin，请在弃权前先"清零"。

所有权

弃权是安全的：开盘由时间戳自动触发，不需要 owner 再做任何事，合约不会被锁死。注意：弃权不会清零 admin，如果不希望留下 admin，请先在上面把 admin 清零，再弃权。

操作日志

每一笔写操作都会先免费模拟（triggerconstantcontract），拿到真实能量消耗和回滚原因后才让你确认发送。模拟失败就不会发，避免 feeLimit 被烧光。
